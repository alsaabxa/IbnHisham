# منصة رصد الغياب والتأخير للموظفات

نسخة أولية عربية RTL ومتجاوبة، مبنية كصفحة HTML واحدة.

## الوظائف الحالية
- لوحة متابعة وإحصاءات.
- رصد الغياب بالنموذج B مع إضافة أكثر من غياب في الشهر.
- أنواع الغياب: مرضية، اضطرارية، أمومة، رعاية مولود، أخرى، بدون عذر.
- عرض التاريخ الهجري والميلادي واليوم.
- رصد التأخير مع حساب دقائق التأخير تلقائيًا.
- تحديد بداية الدوام الرسمي من الإعدادات.
- إدارة الموظفات: إضافة، تعديل، حذف، وإضافة أسماء دفعة واحدة.
- تقارير A وB للغياب والتأخير مع الطباعة وحفظ PDF من المتصفح.
- حفظ مؤقت للبيانات في LocalStorage.

## المرحلة التالية
ربط المنصة بقاعدة بيانات مركزية عبر Google Apps Script + Google Sheets، ثم إضافة توقيع الموظفة من الجوال وربطه بالتقرير، وتطوير نموذج A ليطابق النموذج الرسمي المرفق بدقة أكبر.

## التشغيل
افتح index.html في المتصفح، أو انشر المستودع عبر GitHub Pages أو Netlify أو Cloudflare Pages.
